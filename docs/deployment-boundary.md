# 실행·배포 경계

이 저장소는 준비된 메타데이터를 읽는 Python 추천 패키지다.
적재·Profiling·DQ·승인·실제 데이터 변환은 이 패키지가 실행하지 않는다.

## 현재 구성

| 경로 | 책임 |
| --- | --- |
| `maps_ai_pipeline/` | 입력·출력 계약, 후보 검색·검증, 저장 어댑터와 CLI |
| `examples/synthetic/` | 외부 자료 없이 실행하는 합성 요청 |
| `examples/external/` | 외부 사전과 명시적 합성 업무 규칙을 연결하는 요청 |
| `tests/` | 처리 연결·보류·판본·재실행·충돌 검사 |
| `docs/` | 계약·로컬 실행·배포 경계 |

실제 참조사전·입력 원본·결과·진행 기록은 저장소 밖에서 관리한다.
배포 패키지에는 `maps_ai_pipeline`만 포함한다. 테스트·예시·로컬 자료는 wheel에 포함하지 않는다.
원본·예시 자료를 클라우드에 업로드하는 동작은 없다.

## 호출 방식

Python 3.11 이상에서 모듈로 실행하거나 설치 후 다음 진입점을 사용할 수 있다.

- `maps-ai-pipeline`: 합성 참조 형식의 요청 실행
- `maps-ai-reference-check`: 외부 사전 구조·검색 검사
- `maps-ai-external-run`: 외부 사전 선택 어댑터를 통한 요청 실행

모든 CLI는 입력과 출력 위치를 인수로 받는다. 현재 실행 방법은 [로컬 실행 안내](local-run.md)를 따른다.
모델·클라우드 인증 변수를 요구하지 않으며 유료 API를 호출하지 않는다.

## Azure 연결 전 결정할 항목

| 항목 | 현재 | 연결 전 필요한 작업 |
| --- | --- | --- |
| 실행 호스트 | 로컬 Python | Fabric Notebook 또는 서버 측 작업 호스트 선택 |
| 입력 조회 | 로컬 준비 파일·외부 참조사전 | 읽기 권한·참조 판본·경로 계약 |
| 결과 저장 | 로컬 hard-link 기반 배타 발행 | 클라우드 조건부 생성·완료 상태·재시도 어댑터 |
| 웹 수신 | 미구현 | Backend 수신·저장 중복 방지와 상태 전이 |
| 비밀정보 | 필요 없음 | 선택 서비스의 서버 측 인증 방식 결정 |
| 승인·변환 | 패키지 범위 밖 | 승인 대상 판본과 기존 변환 엔진 계약 |

로컬 hard link를 ADLS·OneLake 객체 저장에 그대로 적용할 수 없다.
Azure 실행 환경에서의 의존성 설치·권한·동시 실행·저장·비용은 아직 검증하지 않았다.
Python 패키지 설치 성공은 Azure 배포 검증을 뜻하지 않는다.
실행 호스트를 결정한 후 필요한 배포 파일만 추가한다.
